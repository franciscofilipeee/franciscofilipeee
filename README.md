## 👨🏻‍💻 Sobre mim

Sou um desenvolvedor Full Stack apaixonado por tecnologia, programação e infraestrutura. Gosto de entender como cada camada se conecta — da interface e experiência do usuário à API, banco de dados, infraestrutura e deploy — para transformar ideias em produtos úteis, rápidos e bem construídos.

Atualmente, estudo **Engenharia de Software na PUC Minas** e concluí o curso **Técnico em Informática pela POLIMIG**, em Belo Horizonte. Fora das telas, carros também fazem parte das minhas paixões: admiro a engenharia, a performance e a atenção aos detalhes que unem esse universo ao desenvolvimento de software.

Meu objetivo é continuar construindo soluções consistentes, explorando boas práticas de infraestrutura e aprendendo todos os dias com novos desafios.
